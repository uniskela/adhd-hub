    Connect your assistant

    Add this Streamable HTTP server in Cursor, Codex, or Claude Code. Set the client’s bearer token from ADHD_HUB_AUTH_TOKEN.

    Install the ADHD Hub skills for all of your projects:

    npx skills add uniskela/adhd-hub -g

    Working on an unreleased local checkout? Use npx skills add ./skills -g instead.

    Restart your assistant and ask it to call session_digest to verify the connection.

    OpenClaw connection & gentle alerts · Optional

    npx skills add uniskela/adhd-hub -g -a openclaw

    Keep OpenClaw on your LAN or Tailscale. The saved bearer token is encrypted with this Hub's access token and is never returned to the browser.
