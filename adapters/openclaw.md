# OpenClaw + ADHD Hub

Use the [OpenClaw connection and alerts guide](../docs/openclaw.md) for the plain-language two-service model, supported skill-install command, Gateway hook-token setup, Hub-to-OpenClaw hook configuration, HTTPS domain/reverse-proxy requirements, and an alert test. Agents should never reveal or paste the hook token; the operator or deployment secret mechanism must provision it. This guide is the canonical source for this adapter so the public wiki and repository guide stay aligned.
